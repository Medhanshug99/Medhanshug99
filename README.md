### What I build

I ship end-to-end products — frontend, backend, and the AI/ML layer that makes them useful — not just demos. Right now that means:

- **IntellMeet AI** — a real-time meeting platform that turns conversations into work: live WebRTC video, AI transcription, and Llama 3 auto-extracting decisions and action items straight into a team task board.
- **DocuParse AI** — a document processing platform (LayoutLMv3 + OCR) for teams tired of manually copying invoice data into spreadsheets.
- **Real Estate Price Predictor** — a full-stack ML app that prices and recommends properties, built for buyers who want a number they can trust before they call an agent.

I'm a 3rd-year CS student at IIIT Ranchi, but I build like the users are already waiting.

- **Frontend** — React, Next.js, TypeScript, JavaScript, Tailwind
